# Website and Repository Link Loop

Ganexity.com should link to this public GitHub repository, and this repository should link back to https://ganexity.com/.

This creates a clear entity loop:

1. The website explains the commercial service.
2. The GitHub repository documents the architecture, use cases, reliability principles, and structured lead summary model.
3. Search engines, AI agents, deep research tools, and coding agents can connect both sources to the same entity: Ganexity.

## Suggested website link text

- Architecture notes
- AI receptionist architecture
- Ganexity public documentation
- AI phone receptionist workflows

## Suggested website pages to link from

- homepage footer
- privacy or legal page, if appropriate
- AI receptionist service page
- use case pages
- technical or documentation page, if added later

## Repository links back to the website

The repository should keep the main website link visible in:

- README.md
- docs/discovery.md
- llms.txt
- future use-case or architecture pages when relevant

## Practical note

The link should be natural and useful. It should not look like a link farm or keyword stuffing. A small footer link or documentation link is enough.
